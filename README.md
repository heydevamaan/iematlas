# IEM Atlas

IEM Atlas is a minimalist website dedicated to my favorite in-ear monitors (IEMs). The project features personal reviews, sound impressions, tuning guides, EQ recommendations, eartip suggestions, and comparisons between different IEMs.

Built using HTML, CSS, and JavaScript, the website aims to provide a clean and user-friendly experience for audio enthusiasts looking to explore and optimize their listening experience.

## Features

* Favorite IEM showcase
* Personal reviews and ratings
* Tuning and EQ guides
* Eartip and DAC recommendations
* Responsive Apple-inspired design

## Tech Stack

* HTML5
* CSS3
* JavaScript

This project is a personal collection of my experiences and recommendations in the world of IEMs.
